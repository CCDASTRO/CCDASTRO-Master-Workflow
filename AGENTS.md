# Independent project

Keep this launcher independent of the post-processing Workflow Manager. Use existing installed tools, not new processing algorithms. Never execute image processing automatically. Session plans are planning paths, not proof of tool input configuration. Preserve source images. Keep signed sources UTF-8 without a BOM and CRLF; never change signed source bytes or rebuild a signed manifest. Publish only after PixInsight verifies both the script and final update manifest. Record actual test scope, not presumed processing outcomes. Do not bundle vendor code or assets.
